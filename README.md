# 📂 Python Folder Organizer

## 📌 Overview

A Python utility that automatically organizes files into separate folders based on their file extensions.

## 🚀 Features

- Organizes files automatically
- Creates folders if they don't exist
- Supports Images, Videos, Audio, Documents, Archives, Scripts and Others
- Uses Python's os and shutil modules

## 🛠 Technologies Used

- Python
- os
- shutil

## ▶️ How to Run

```bash
python main.py
```

## 📷 Example

Before:

```
Downloads/
├── photo.jpg
├── movie.mp4
├── resume.pdf
├── song.mp3
```

After:

```
Downloads/
├── Images/
│   └── photo.jpg
├── Videos/
│   └── movie.mp4
├── Documents/
│   └── resume.pdf
├── Audio/
│   └── song.mp3
```
